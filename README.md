# qwertifyed.github.io

Документация систем для Roblox, построенная на [Docusaurus](https://docusaurus.io/) и размещённая на GitHub Pages.

## Как добавить новую систему

1. Создай каталог `systems/<имя-системы>/`
2. Положи в него Markdown-файлы в `systems/<имя-системы>/docs/`
3. Добавь `systems/<имя-системы>/sidebars.js`:

```js
/** @type {import('@docusaurus/plugin-content-docs').SidebarsConfig} */
const sidebars = {
  <имя>Sidebar: [{type: 'autogenerated', dirName: '.'}],
};

module.exports = sidebars;
```

4. Зарегистрируй плагин в `docusaurus.config.js` (блок `plugins`):

```js
[
  '@docusaurus/plugin-content-docs',
  {
    id: '<имя-системы>',
    path: 'systems/<имя-системы>',
    routeBasePath: '<имя-системы>',
    sidebarPath: './systems/<имя-системы>/sidebars.js',
    editUrl: 'https://github.com/qwertifyed/qwertifyed.github.io/tree/main/',
  },
],
```

5. Добавь ссылку на систему в навбар и футер, карточку — на главной странице (`src/pages/index.js`)
6. Запушь в `main` — GitHub Actions автоматически соберёт и опубликует сайт

## Локальная разработка

```bash
npm install
npm start        # dev-сервер на http://localhost:3000
npm run build    # production-сборка в build/
npm run serve    # локальный просмотр собранного сайта
```
