# Guard

Система защиты для Roblox-игр: анти-абуз, фильтрация действий игроков и логгирование подозрительной активности.

## Возможности

- Обнаружение абуза физики (speed hacking, noclip)
- Проверка предметов и инвентаря игрока
- Логгирование действий в DataStore
- Автоматическое предупреждение и бан
