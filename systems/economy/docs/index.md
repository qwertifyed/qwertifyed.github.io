# Economy

Экономическая система для Roblox-игр: валюты, магазины, транзакции и балансы игроков.

## Возможности

- Множественные валюты (монеты, кристаллы, донат)
- Магазины с предметами и лимитами
- История транзакций в DataStore
- Админ-команды для начисления и списания
